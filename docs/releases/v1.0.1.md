# AlphaPro v1.0.1

AlphaPro v1.0.1 正式发布：全面升级相册浏览与 10-bit HEIF 解码管线、精简无线快门交互、解决后台轨迹存储崩溃，并带来动态特性引导与全系统预测性返回手势。

## 本次更新亮点

### 1. 相册浏览与 10-bit HEIF 软解管线全面升级
- **内置原生 HEIF 解码器**：集成交叉编译的 `libheif` + `libde265` 软件解码引擎（针对主流设备精简保留 `arm64-v8a` 架构，符合 Android 15+ 16KB 页面对齐标准）。
- **智能预览解码策略**：系统解码优先（原生支持 4:2:0 HEIF 的设备直接硬件解码），遇 4:2:2 等未受系统支持的格式自动平滑回退至多核软件解码；小缩略图支持同组 RAW 相机渲染回退，彻底解决 4:2:2 图像持续加载与解码报错。
- **PTP 传输会话加固**：重构会话意图周期与取消收敛机制，彻底解决大图预览与下载并发抢占导致的 `Camera session is closed` 传输中断。
- **真实相册导出发布**：转码生成的高质量 JPEG 经由 MediaStore 真正写入并发布至系统相册；大图转换串行保护与取消清理，避免内存溢出与无效传输。
- **下载格式弹窗排版优化**：弹窗宽度自适应扩展，消除单选按钮冗余留白，标题与推荐徽章防挤压折行；转码为 JPEG 选项默认状态联动全局设置策略。
- **大图沉浸式浏览与交互**：大图详情支持自然左右横划翻页（缩放放大时自动锁定翻页以便平移检焦），支持在预览界面直接勾选多选并一键批量下载；相册列表支持长按照片直接进入多选模式。
- **故障透明诊断**：缩略图加载失败支持点击破图图标查看并复制具体的阶段错误详情。

### 2. 无线快门交互大幅精简
- **双模式收敛**：顶层精简为「标准遥控」与「定时拍摄」两态，消除单张与连拍的冗余切换。
- **统一快门手势**：轻点短按保底击发完整单张快门脉冲，按住不放自动连拍（机身设为连拍驱动），松手即停。
- **视觉居中与按键加大**：160dp 快门圆盘内部改为纯图标居中展示，彻底消除文字挤压导致的偏心问题；半按对焦锁定（AF-ON）与视频录制（REC）按钮加大为 48dp 大尺寸并排对称排布，单手握持极易盲操。

### 3. 后台 GPX 轨迹记录与存储修复
- **私有存储隔离**：自动轨迹记录迁移至应用私有目录（`filesDir/tracks`），彻底根除 Android 11+ 分区存储在公共 Documents 目录写入引起的 `EACCES (Permission denied)` 崩溃。
- **心跳守护解耦**：轨迹磁盘写入与 5 秒 BLE 坐标心跳完全解耦；原子临时文件替换写入，即使存储受阻也绝不中断相机定位同步，支持通过系统分享导出 GPX 文件。
- **设置策略联动**：关闭 GPX 记录开关即刻停止记录新轨迹点，不影响相机 GPS 定位同步。

### 4. 全新动态使用引导与预测性返回手势适配
- **动态矢量特性介绍**：四页全新 Canvas 动画演示（GPS对时、相册传输、无线快门、FTP直传），设置页支持随时回看。
- **独立任务栈与防误触防护**：采用独立 `OnboardingActivity`；入口使用“稍后了解”与显式确认退出弹窗，有效防御第三方自动跳广告无障碍服务误触发。
- **Android 14+ 预测性返回手势全面适配**：首次引导多页翻页支持微缩放渐变跟随，引导首页与设置回看自动交由系统原生接管，展现优雅的 Cross-Activity 与 Back-to-Home 预测性退出动效。
- **后台定位与电池优化配置卡片**：提供公开的设置跳转引导，实时检测授权状态并刷新。

## 安装与兼容性

- 下载附件 **AlphaPro-v1.0.1.apk**，适用于 Android 8.0（API 26）及以上系统。
- 架构支持：精简优化为 **`arm64-v8a`**（支持 64 位现代 Android 手机与平板，体积大幅缩减至 14MB 左右）。
- APK 使用项目正式通用签名（RSA 4096），可直接覆盖安装升级旧版本。
- 发布标签：`v1.0.1`。
- App 内部构建号：`1.0.1.22`（versionCode `100010022`）。
- 附件 **SHA256SUMS.txt** 提供安装包的 SHA-256 校验值。

## 验证与使用须知

- 本版本经全套 283 项默认 JVM 单元测试、7 项 Android 运行时测试及实际 10-bit 4:2:2 C++ 解码测试回归验证。
- 请在索尼机身开启蓝牙遥控及 Wi-Fi 连接就绪状态；驱动模式、快门速度等曝光参数仍由相机机身完全控制。
- 10-bit 4:2:2 HEIF 转码导出输出为 8-bit 高质量 sRGB JPEG，受限于移动设备安全内存预算，极超大像素图像可能受解码限制。
- 卸载应用会清除私有轨迹记录，如需保留路线请提前在设置中通过“分享”导出 GPX 文件。
