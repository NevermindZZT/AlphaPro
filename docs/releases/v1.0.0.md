# AlphaPro v1.0.0

AlphaPro 首个正式 Release：面向 Sony Alpha 相机的开源 Android 伴侣应用。

## 主要功能

- **BLE 定位与连接**：相机定位同步、5秒周期更新、后台服务与设备在场感知。
- **Wi-Fi 相册与传输**：相机直连、PTP/IP 浏览、RAW/JPEG/HIF 文件分组、独立高清预览与下载、HEIF 转 JPEG 导出。
- **无线快门**：单张拍摄、半按 AF、录像开关、按住连拍、B 门长按／定时、手机端间隔拍摄。
- **Material You 界面**：动态取色、深浅主题、公共操作组件，以及系统语言／简体中文／English 选择。

## 本次无线快门更新

- 操作说明、模式参数、160dp 快门和紧凑 AF／录像按钮整合为同一操作卡片；安全说明单独分层，改善稀疏页面的留白。
- 连拍按住拍摄、松手请求停止；B 门支持长按和定时；参数滑动条支持精确数值对话框。
- 增加手势令牌、固定连接会话、取消清理、前台序列保护及固定停止入口。
- 索尼蓝牙 B 门使用开始／结束完整按键，不把物理快门的抬起语义直接套用到蓝牙控制。

## 安装

- 下载附件 **AlphaPro-v1.0.0.apk**，Android 8.0（API26）及以上。
- APK 使用项目现有正式签名，可按 Android 的签名/版本校验规则覆盖同签名旧包。
- 发布标签：`v1.0.0`。
- App 内部构建号：`1.0.0.13`（versionCode `100000013`），沿用 Git 提交次数生成规则；与发布标签命名不同。
- 附件 **SHA256SUMS.txt** 提供 APK 的 SHA-256 校验值。

## 使用边界

- 请在机身开启蓝牙遥控，并自行完成驱动、曝光等设置；App 不会自动切换机身拍摄模式。
- 连拍需机身连续拍摄驱动；B 门需兼容的 M／BULB 设置，使用 App 定时时关闭机身 BULB 定时器。
- 手机拍摄序列需保持页面前台；离开或锁屏会停止手机序列并尝试释放／结束操作。断连或结果不明时请检查机身，无法保证无线故障后机身已结束曝光。
- 计时为手机计划，触发次数不等于照片已保存；间隔需留出曝光、处理及写卡时间。
- 已知 UI 限制：亚秒级长按结束后没有持久“已结束”标签；小屏／大字体下部分错误说明需滚动查看，停止／异常确认入口固定保留。
